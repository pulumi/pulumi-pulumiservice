## 1.9.0

### Bug Fixes

- Fixed `DeploymentSettings` with a `github` or `vcs` block reporting changes on every refresh, because Pulumi Cloud returns GitHub settings in both blocks [#1201](https://github.com/pulumi/pulumi-pulumiservice/issues/1201)
- Marked properties that carry credentials as secret: the S3-compatible configuration on `api.AuditLogExportConfiguration`, the source, executor and operation contexts on `api.deployments.Settings`, and the request and definition on `api.deployments.ScheduledDeployment`. [#1446](https://github.com/pulumi/pulumi-pulumiservice/issues/1446)
- Stopped marking `hasSecret` on webhooks, `secretRotationRequest` on `api.esc.EnvironmentSchedule` and `groupAccessTokenExpiration` on `api.integrations.GitLabIntegration` as secret, so their values show in previews. [#1446](https://github.com/pulumi/pulumi-pulumiservice/issues/1446)
